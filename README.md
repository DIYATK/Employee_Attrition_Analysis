## Employee Attrition Analysis – Excel Dashboard

### Project Overview

This project focuses on analyzing employee attrition patterns and understanding the factors influencing employee turnover.

### Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Charts & Slicers

### Key Insights
- Analyzed attrition based on gender, education, city and payment tier.
- Compared employees who stayed and left the organization.
- Identified differences in attrition across different cities and payment tiers.
- Used joining year to understand employee attrition patterns.

### Dashboard
Created an interactive Excel dashboard using Pivot Tables, charts, slicers and KPI metrics.
